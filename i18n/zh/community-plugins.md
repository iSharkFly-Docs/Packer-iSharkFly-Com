# HashiCorp 维护的插件

以下插件（即构建器、配置器和后处理器）由 HashiCorp 维护。不在此列表中的插件由社区维护，HashiCorp 不会积极贡献，但它们仍然随 Packer 一起分发。如果你希望看到这些插件的功能或错误修复，请考虑提交 pull request，或向 HashiCorp 维护者咨询如何开始贡献。

## 构建器

- Amazon EC2
- Azure
- Docker
- Google Cloud
- VMware
- VirtualBox

## 配置器

- File
- HCP SBOM
- InSpec
- PowerShell
- Shell
- Windows Restart
- Windows Shell

## 后处理器

- Amazon Import
- Artifice
- Docker
- Local Shell
- Manifest
- Vagrant
- Vagrant Cloud
