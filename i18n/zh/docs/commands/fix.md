# `packer fix` 命令参考


`packer fix` 命令接受一个模板，找出其中向后不兼容的部分，并将其更新为可与最新版本 Packer 一起使用的格式。在更新到新的 Packer 版本后，你应该运行 fix 命令以确保你的模板可以与新版本一起使用。

::: info
**仅限 JSON 模板的命令**：你不能使用 `packer fix` 命令来更新 HCL2 模板。
:::

fix 命令会将更改后的模板输出到标准输出，因此如果你想将其保存到文件，应该使用标准操作系统特定的技术重定向标准输出。例如，在 Linux 系统上，你可能需要这样做：

```shellsession
$ packer fix old.json > new.json
```

如果修复因任何原因失败，fix 命令将以非零退出状态退出。错误消息会出现在标准错误上，所以如果你重定向了输出，你仍然会看到错误消息。

::: info
**即使 Packer fix 没有对模板做任何更改**，模板也会被输出到标准输出。配置键的顺序和缩进等内容可能会更改。然而，输出格式是为人类可读性而美化打印的。
:::

fix 命令执行的完整修复列表可以在帮助输出中看到，可以通过 `packer fix -h` 查看。

## 选项

- `-validate=false` - 禁用对修复后模板的验证。默认为 true。
