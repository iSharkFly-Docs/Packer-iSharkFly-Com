# 下载 Packer 社区项目

Packer 拥有一个充满活力的贡献者社区，他们在 Packer 之上构建了许多出色的工具。还有很多项目展示了 Packer 模板的强大功能。

## 第三方插件

要了解更多关于如何使用社区插件或如何构建自己的插件，请参阅[扩展 Packer](/docs/plugins/install) 的文档。

如果你构建了一个插件并希望将其添加到此社区列表中，请提交 pull request，以便我们记录你的贡献。

请参阅以下主题，了解由 Packer 用户和供应商社区构建的插件。我们不测试或维护社区插件。

- [社区配置器](/docs/provisioners/community-supported)
- [社区后处理器](/docs/post-processors/community-supported)


## 模板

- [bento](https://github.com/chef/bento) - 用于构建最小化 Vagrant 基础镜像的 Packer 模板

- [boxcutter](https://github.com/boxcutter) - 社区驱动的模板和工具，用于创建云、虚拟机、容器和裸金属操作系统环境

- [cbednarski/packer-ubuntu](https://github.com/cbednarski/packer-ubuntu) - 用于 Vagrant 的 Ubuntu LTS 虚拟机

- [geerlingguy/packer-ubuntu-1604](https://github.com/geerlingguy/packer-ubuntu-1604) - 使用 Ansible 配置器的 Ubuntu 16.04 最小化 Vagrant Box

- [jakobadam/packer-qemu-templates](https://github.com/jakobadam/packer-qemu-templates) - 各种操作系统的 QEMU 模板

- [lucidone/baseliner](https://git.sr.ht/~lucidone/baseliner) - 使用 QEMU + Ansible 配合 Packer 的示例

- [packer-build](https://github.com/tylert/packer-build) - 为 Vagrant、VirtualBox 和 QEMU 构建全新的 Debian 和 Ubuntu 虚拟机镜像

- [packer-windows](https://github.com/joefitzgerald/packer-windows) - Windows Packer 模板

- [packer-baseboxes](https://github.com/taliesins/packer-baseboxes) - 用于 Packer 构建基础镜像的模板

- [vmware/packer-examples-for-vsphere](https://github.com/vmware/packer-examples-for-vsphere) - 使用 HashiCorp Packer 和 Packer Plugin for VMware vSphere 在 VMware vSphere 上自动创建虚拟机镜像及其客户操作系统的示例

- [Parallels/packer-examples](https://github.com/parallels/packer-examples) - 如何在 macOS、Windows 和 Linux 上使用 Packer 与 Parallels Desktop 自动创建虚拟机镜像及其客户操作系统的示例

## 封装器

- [packer-config](https://github.com/ianchesal/packer-config) - 一个 Ruby 模型，让你可以用 Ruby 构建 Packer 配置
- [packerlicious](https://github.com/mayn/packerlicious) - 用于生成 Packer 模板的 Python 库
- [packer.py](https://github.com/mayn/packer.py) - 用于执行 Packer CLI 命令的 Python 库
- [racker](https://github.com/aspring/racker) - 用于生成 Packer 模板的固执己见的 Ruby DSL

## 其他

- [suitcase](https://github.com/tmclaugh/suitcase) - 基于 Packer 的 CentOS 操作系统镜像构建系统
