# Packer 文档

Packer 是一个社区工具，可以从单一源模板为多个平台创建相同的机器镜像。人们通常使用 Packer 创建黄金镜像，供组织内各团队在云基础设施中使用。

要安装 Packer 并学习标准的 Packer 工作流程，请尝试[快速入门教程](https://developer.hashicorp.com/packer/tutorials)。

## HCP Packer

HCP Packer 注册表存储关于制品的元数据。你可以使用注册表跟踪 Packer 构建的制品信息，明确指定哪些制品适合测试和生产环境，并在 Packer 和 Terraform 配置中查询要使用的正确制品。

请参阅以下资源开始使用：

- [HCP Packer 文档](https://developer.hashicorp.com/hcp/docs/packer)
- [HCP Packer 教程](https://developer.hashicorp.com/packer/tutorials/hcp-get-started)
- [登录 HCP 门户](https://portal.cloud.hashicorp.com)
