# 社区后处理器概述

以下后处理器由 Packer 社区的各个成员开发和维护，而非 HashiCorp。有关如何使用社区后处理器的更多信息，请参阅我们关于[扩展 Packer](/docs/plugins/creation/) 的文档。

### 社区后处理器

- [Exoscale Import 后处理器](https://github.com/exoscale/packer-plugin-exoscale) - 用于从磁盘镜像文件导入 Exoscale 自定义模板的后处理器。
