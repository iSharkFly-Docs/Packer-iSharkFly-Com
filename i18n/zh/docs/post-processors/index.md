# 后处理器概述

后处理器在构建器和配置器之后运行。后处理器是可选的，你可以使用它们来上传制品、重新打包文件等。文档包含每种后处理器类型的页面。

请参阅 [`post-processor`](/docs/templates/hcl_templates/blocks/build/post-processor) 和 [`post-processors`](/docs/templates/hcl_templates/blocks/build/post-processors) 块文档，了解有关使用后处理器的更多信息。
