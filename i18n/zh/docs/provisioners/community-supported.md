# 社区配置器

以下配置器由 Packer 社区的各个成员开发和维护，而非由 HashiCorp 开发维护。有关如何使用社区配置器的更多信息，请参阅[开发插件](/docs/plugins/creation/)。

- [Comment 配置器](https://github.com/SwampDragons/packer-provisioner-comment) -
  示例配置器，允许你用气泡文本注释来注解你的构建。

- [Windows Update 配置器](https://github.com/rgl/packer-plugin-windows-update) -
  用于优雅处理 Windows 更新及其导致的重启的配置器。

- [S3 配置器](https://github.com/spacechunks/packer-plugin-s3) - 
  从 S3 检索对象并将其存储到给定目标的配置器。
