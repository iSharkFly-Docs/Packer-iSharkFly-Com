# Packer v1.13 发布说明

本页描述 Packer v1.13 中的更改。有关所有版本的信息，请参阅 [Packer 仓库](https://github.com/hashicorp/packer/releases)。

## 新功能

此版本包括以下更新。

### Shell 配置器增强

shell 配置器的 inline 字段现在支持直接执行脚本，包括那些带有自己 shebang (#!) 行的脚本。
此增强功能允许你将完整脚本作为内联命令提供，从而通过 templatefile 等工具启用动态脚本。

### 新函数

作为 Packer 1.13 的一部分，我们引入了以下函数。

* `sum`：接受数字列表或集合，返回这些数字的总和。
* `startswith`：接受两个值：要检查的字符串和前缀字符串。如果字符串以该精确前缀开头，函数返回 true。
* `endswith`：接受两个值：要检查的字符串和后缀字符串。如果第一个字符串以该精确后缀结尾，函数返回 true。

### Packer fmt 命令支持格式化多个 HCL 文件

添加了 packer fmt 命令一次格式化多个 HCL 文件的功能。
此增强功能允许用户在单个命令调用中格式化多个文件。

### 顶层 hcp_packer_registry 块支持

添加了在 Packer 配置的顶层定义 hcp_packer_registry 块的支持。这使得可以直接在根 schema 中改进 HCP Packer 注册表的管理和引用。
还添加了对顶层多个 hcp_packer_registry 块的验证。

## 错误修复

### 文档更新

更新了文档以明确说明上传目录时需要尾部斜杠，无论客户操作系统是什么。
此澄清旨在确保一致的行为并防止混淆，特别是对于 Windows 用户。

### --use-sequential-evaluation 标志现在在 Packer Console 中工作

修复了使用 packer console 时使用 --use-sequential-evaluation 标志导致错误的问题。
该标志现在已正确包含在 packer console 支持的选项中，并按预期工作。
从 fix 子命令中删除了此标志，因为在那里未使用或不需要。

### 内联 PowerShell 命令

在配置器执行的内联 PowerShell 命令周围添加了包装器，以捕获错误并确保如果任何命令导致错误，Packer 构建会失败。

### 保留用户定义的变量文件顺序

确保 Packer 现在保留用户输入的变量文件的用户定义顺序。
此更改保持了变量的预期优先级，尊重命令行上指定的顺序。
