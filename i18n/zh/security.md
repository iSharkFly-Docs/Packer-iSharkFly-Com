# Packer 安全

我们理解许多用户对 HashiCorp 及我们构建的工具给予了高度信任。我们应用最佳实践并专注于安全，以确保能够维护社区的信任。

我们非常感谢任何负责任地披露漏洞的努力。

如果你想报告漏洞，请查看 [HashiCorp 安全页面](https://www.hashicorp.com/security)，其中有正确的联系邮箱以及我们的 PGP 密钥。请**不要为安全问题创建 GitHub issue**。

如果你报告的不是安全敏感漏洞，请在 [Packer GitHub 仓库](https://github.com/hashicorp/packer)提交 issue。
